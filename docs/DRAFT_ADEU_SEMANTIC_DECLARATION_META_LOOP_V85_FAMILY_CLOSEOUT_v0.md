## Alignment Judgment

`V85-A` opened source-bound semantic declaration request intake, declaration
source indexes, semantic act witness rows, negative cue rows, resident-model
competency rows, and non-authority guardrails over released `V84-C` substrate
without treating operator turns, generated declaration candidates, support
doctrine, or model output as declaration authority. `V85-B` added canonical
meta lookup indexes, semantic operator/class registry rows, obligation-family
registry rows, and pointer lookup fixtures without converting lookup into
semantic truth, registry rows into runtime behavior, obligation-family lookup
into obligation expansion, or opaque pointer obedience into natural semantic
binding correctness. `V85-C` added semantic declaration review summaries,
post-semantic-declaration-review handoffs, and family closeout alignment
without obligation expansion, evidence contracts, audit taskpacks, transition
tables, implementation, runtime behavior, product authority, graph authority,
recursive policy amendment, or `V86` selection.

The three slices align:

- declaration request recordability remains weaker than semantic declaration
  review eligibility;
- support docs, generated declarations, operator preference, and broad task
  labels remain context unless source-bound by concrete current witnesses;
- semantic declaration sessions provide stable identity across request,
  lookup, registry, obligation-family, fixture, summary, and handoff rows;
- declared semantic acts remain candidates until later lookup / summary
  review; `V85-A` does not select canonical declarations by itself;
- ambiguity, abstain, malformed input, registry gaps, and support-only context
  fail closed instead of being repaired into canonical declarations;
- source witnesses are row-shaped and distinguish direct/current evidence
  from support-only, absence, conflict, or contextual evidence;
- negative cues route implementation, execution, runtime, product, release,
  obligation-expansion, skip-lookup, and invented-class pressure to guardrails;
- resident-model competency is framed as pointer obedience, artifact-shape
  obedience, bounded local judgment, declared uncertainty routing,
  order/duplicate preservation, unknown-pointer abstention, no unauthorized
  transition, and stop-at-schema-boundary posture;
- canonical pointer grammar fails closed on unknown classes, unknown versions,
  malformed pointers, ambiguous parses, and unregistered aliases;
- operator registry entries and class registry entries are lookup semantics
  only and do not become runtime behavior, dispatch authority, or local
  authority;
- obligation-family registry rows name later expansion pressure only and do
  not instantiate obligations;
- opaque pointer fixtures prove pointer obedience only, not natural semantic
  binding correctness;
- semantic declaration review summaries preserve released `V85-A/B` source,
  session, candidate, lookup, registry, obligation-family, and guardrail

  refs, obligation-family refs, guardrail refs, no carried blockers, and

  lookup, lookup conflict, missing guardrails, support-only sources, invented
