## Purpose

Freeze the bounded `V74-B` starter slice so the repo can project typed
adjudication and model-output comparison state over released `V74-A`
case-view, source-index, and guardrail rows without turning visibility into
ratification, product authorization, benchmark truth, model selection,
exception resolution, runtime permission, release authority, or dispatch.

`vNext+207` authorizes docs plus the next implementation path over the
existing repo-owned `adeu_repo_description` package. It does not authorize
`V74-C` decision visibility contracts, ratification-review workbench
projection, post-projection handoff, `V75` dispatch, live product UI, operator
command execution, product authorization, runtime permission, release
authority, external contest participation, or recursive self-approval.

The active `V74-B` implementation may add its own schema, model, validator,
fixture, and test files under this lock. That implementation work is distinct
from product UI or benchmark work. `V74-B` may project typed adjudication and
comparison state and keep exceptions visible; it must not record that a
candidate is ratified, adopted, product-authorized, released, executable,
globally model-ranked, dispatched, or recursively self-approved.

## Required Deliverables / Exit Conditions

- typed model and schema exports for:
  - `repo_typed_adjudication_case_view@1`
  - `repo_model_output_comparison_projection@1`
  - `repo_projection_exception_visibility_register@1`
- deterministic reference and reject fixtures for the bounded `V74-B` starter
  family only
- a hand-curated reference fixture seeded from released `V74-A` case-view,
  source-index, and guardrail fixture material
- validators that prove:
  - typed case rows reference known released `V74-A` case-view refs
  - typed case rows do not treat conceptual-diff support docs as released
    schema, ratification, adoption, product, or release authority
  - comparison projection rows carry prompt refs, model-output refs,
    model-output provenance rows, adjudicator schema refs, and structured
    comparison axis rows
  - comparison axes carry bounded claim horizons, source refs, exception refs
    where needed, and non-benchmark guardrails
  - comparison projection cannot rank models globally or select a future model
  - exception rows reference known case, typed case, or comparison projection
    refs and cannot be omitted when source gaps, dissent, regressions, or
    authority blockers are known
  - exception rows cannot be marked resolved by `V74-B`
  - product-pressure typed cases cannot become product authorization
  - typed case or comparison projection rows cannot create new ratification,
    outcome verdicts, implementation authority, release authority, product
    authorization, runtime permission, dispatch, or external contest
    participation
- tests that prove:
  - typed adjudication case without released `V74-A` case refs is rejected
  - conceptual-diff support doc as released schema is rejected
  - comparison projection without prompt or model-output source refs is
    rejected
  - comparison projection without model-output provenance rows is rejected
  - comparison projection that ranks a model globally is rejected
  - comparison axis without source evidence is rejected
  - comparison axis without bounded claim horizon or non-benchmark guardrail is
    rejected
  - product wedge projected as product authorization is rejected
  - exception register that omits known source gap, dissent, regression, or
    authority blocker is rejected
  - exception marked resolved by `V74-B` is rejected
  - typed case that creates new ratification or outcome verdicts is rejected
  - comparison projection that authorizes implementation, release, product,
    runtime, dispatch, or external contest participation is rejected
- no `V74-C` decision visibility contract, ratification-review workbench
  projection, post-projection handoff, family closeout alignment, live UI,
  product authorization, runtime permission, release authority, external
  contest participation, or `V75` dispatch lands in this slice.
