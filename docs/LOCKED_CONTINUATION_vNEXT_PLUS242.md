## Purpose

Freeze the bounded `PB-PY-0-A` starter slice so the repo can translate released
`V85` semantic declaration / lookup substrate, hardened conceptual-first
retrieval doctrine, and ProgramBench cleanroom reconstruction pressure into a
source-bound local cleanroom profile and fixture-contract review substrate.

`vNext+242` authorizes docs plus the next implementation path over the
existing repo-owned `adeu_benchmarking` package. It does not authorize
`PB-PY-0-B`, `PB-PY-0-C`, Python realization records, Python reconstruction
plans, witness templates, fixture implementation, generated code, official
ProgramBench runner integration, official task execution, hidden-test handling,
benchmark scoring, model ranking, hidden-test inference, original source
lookup, decompilation, internet lookup, external repository lookup, command
execution, tool invocation, target mutation, runtime transition, product
authority, graph-memory authority, recursive policy amendment, PR creation,
commit, merge, release, `V86`, `V87`, `V88`, or other future-family selection.

Controlling invariant:

```text
PB-PY-0-A may make cleanroom reconstruction profile, evidence-source,
concept-seed, non-authority guardrail, and fixture-contract records
reviewable, but it may not implement Python realization records, generate code,
run ProgramBench, expose forbidden evidence, claim benchmark truth, or build a
fixture instance.
```

Operational cleanroom invariant:

```text
Forbidden inference stores must not be registered, mounted, queried, or exposed
to the worker during inference. Classification is not sufficient if the worker
can already access the material.
```

  - `program_odeu_concept_boundary_seed@1`
  - `programbench_cleanroom_evidence_source_index@1`

- deterministic reference and reject fixtures for the bounded `PB-PY-0-A`
  starter family only;
- validators that prove:
  - public descriptors are advisory context only;
  - hidden tests are not inference evidence;
  - forbidden inference stores are not worker-visible, registered, mounted,
    queried, or exposed during inference;
  - public descriptor rows remain advisory/context-only and cannot become
    evaluation truth;
  - inference, local-development, evaluation, and postmortem phases remain
    separately constrained;
  - concept seed rows do not prove task concept presence and do not authorize
    Python realization;
  - concept seed boundary-outline rows remain advisory seed material, not full
    concept-boundary authority;
  - fixture contract rows do not instantiate a local fixture;
  - local probes cannot be marked hidden-test equivalence;
  - `PB-PY-0-A` creates no Python realization records, reconstruction plans,
    witness templates, local fixture instances, comparison packets, probe
    audits, generated code, official runner integrations, benchmark scores, or
    model rankings.
